 Skill Ledger

### Evidence-Driven Skill Verification & Scoring Platform

**Skill Ledger** is a profile-based skill evaluation system that converts a user's **projects, certificates, and achievements** into a transparent, evidence-backed skill profile.

Instead of relying only on self-declared skills, Skill Ledger evaluates the **evidence behind each claim** through credential verification, GitHub repository analysis, authenticity scoring, and evidence recency.

**🚀 What is Skill Ledger?**

Traditional resumes often look like:
....
Python,
Machine Learning,
GitHub,
Leadership,
Claude Code

**Skill Ledger takes a different approach:**
Skill Claim
     ↓
Evidence Submitted
     ↓
Verification / Analysis
     ↓
Authenticity Evaluation
     ↓
Recency Adjustment
     ↓
Skill Score
     ↓
Live Profile


**Current Profile Interface**
